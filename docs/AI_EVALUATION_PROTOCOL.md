# 30종 AI 개선·재학습 평가 규약

2026년 10월 27일. 최종 test 결과를 보기 전에 비교 조건과 모델 적용 기준을 정한다. 이번 변경은 기준 AI의 무효 공격 반복·교체 판단을 수정하고 실제 재학습을 수행하는 작업이다. 성공을 미리 가정하거나 이전 6종 평가 승률과 새 평가 승률을 같은 모집단으로 비교하지 않는다.

## 데이터와 규칙

- 전투 판정은 게임과 같은 Showdown 0.11.11 어댑터, 레벨 50·3대3·동일 행동 마스크를 사용한다.
- 콘텐츠의 30종을 공유하고, 종 3개 조합의 순서를 제거한 hash로 train/validation/test를 나눈다. 조합 수는 각각 2,842 / 637 / 581개다.
- 각 분할은 별도의 도구·EV 빌드를 사용한다. 같은 빌드와 같은 종 조합은 분할 사이에 겹치지 않으며, 다른 슬롯 순서를 새로운 팀으로 간주하지 않는다.
- 종·기술·전투 규칙은 공유한다. 이 평가는 미학습 종이나 전 도감에 대한 일반화 검사가 아니다. 원본 영입 풀의 공격 역할과 맞지 않는 일부 EV는 학습 데이터 안에서 정규화한다.
- 학습·validation·test seed 범위도 분리하고 체크포인트에 학습 데이터·seed 계약을 기록한다. 기존 6종 bootstrap은 새로운 데이터 계약 이전의 비교 모델이며 새 학습의 시작 가중치로 사용하지 않는다.

## 학습과 후보 선택

- 수정한 공개 정보 휴리스틱의 행동을 모으는 모방 학습 8,192표본과 마스크를 보존한 PPO 65,536단계를 별도 예산으로 실행한다.
- PPO는 자기 대전 모델·휴리스틱·위력 우선 상대를 섞는다. 자기 대전 상대의 별도 p2 관측·정책 호출 수·스냅샷 갱신을 기록한다.
- 고정 validation에서만 후보를 선택한다. 자연 무승부와 턴/입력 제한으로 끝난 truncation을 구분하고, 제한 초과가 후보 선택의 무승부 보상으로 유리하게 작용하지 않게 한다.
- 선택한 후보를 고정한 뒤 test를 실행한다. test 결과를 보고 같은 test에 맞추어 재학습하거나 후보를 다시 고르지 않는다.

## 최종 비교와 적용 기준

후보와 수정한 규칙 AI를 각각 랜덤·위력 우선·수정 휴리스틱·이전 bootstrap 모델 상대로 상대별 500경기 이상 평가한다. 같은 test 분할·seed·선두 배치를 사용한다. 승·패·자연 무승부·truncation·불법 행동·평균 턴·추론 평균/p95·실행 시간·95% Wilson 승률 구간을 보고한다. 양쪽 모두 자기 시점의 허용 정보만 받는다.

일반/어려움 모드는 규칙 AI를 유지한다. 기존 신경망 난이도의 bootstrap을 새 실험 모델로 바꾸는 최소 기준은 다음과 같다.

1. 최종 평가의 불법 행동이 0이고 저장된 관측·행동·엔진 계약이 일치한다.
2. 이전 bootstrap 상대 500경기 승률의 95% Wilson 하한이 50%를 넘는다.
3. 각 상대의 제한 초과 비율이 5% 이하이고 추론 p95가 50ms 이하이다.

이 기준을 통과해도 휴리스틱보다 강하다고 자동으로 표시하지 않는다. 휴리스틱 상대 승률과 신뢰구간을 함께 공개한다. 최소 기준을 통과하지 못하면 기존 실전 모델을 유지하고 새 후보와 재현 가능한 보고서를 보관한다. 강화학습을 완료했다는 사실과 실전 기본 모델로 승격했다는 사실은 구분한다.

새 탐험은 기본(`normal`)과 전략(`hard`) 중 선택한다. 전략 탐험에서 새로 시작하는 정예·보스 전투에 개선한 규칙 정책을 적용하고, 기본 탐험과 일반 전투는 위력 우선 정책을 사용한다. 새 정예·보스 빌드의 누락된 EV는 공격 역할에 맞춰 채우며 명시한 EV는 보존한다. 이미 저장된 전투는 기존 정책과 checkpoint를 유지하며, 새 정책 식별자가 없는 과거 전투는 기존 위력 우선 정책으로 복원한다. 콘텐츠 파일·기존 런 저장 버전을 바꾸지 않는다.

## 고정 후보의 추가 확인

최초 test의 규칙 AI 대칭 대전에서 54.6%가 나와 팀·좌석 배치 영향을 확인하기 위한 별도 평가를 추가했다. 이 추가 확인은 최초 결과를 본 뒤 정한 절차이며, 최초 사전 기준과 구분한다. 모델·정책·학습 예산·선택 체크포인트는 고정한 채 독립 seed 3,000,000–3,000,249를 사용한다. 각 쌍은 두 팀과 엔진 seed를 고정하고 두 번째 경기에서 정책의 p1/p2 소유권을 교환한다.

후보 대 bootstrap, 규칙 v2 대 기존 규칙, 규칙 v2 대칭 비교를 각 250쌍·500경기씩 실행한다. 쌍 내부의 의존성을 반영한 pair-bootstrap 95% 구간과 경기별 기술 통계인 Wilson 구간을 함께 기록한다. 후보 대 bootstrap은 두 구간의 하한이 모두 50%를 넘는지도 추가 적용 조건으로 확인한다. 결과로 재학습하거나 후보를 다시 선택하지 않는다. 실제 결과와 한계는 [학습 기록](../pokemon_rl/training/README.md)에 보관한다.
