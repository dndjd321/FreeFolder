HP/PP는 해당 구간에 도달한 런의 파티 합계 비율 평균이다. 전투 중 누적 소모와 다르며 도달 표본 수가 다른 구간을 동등한 집단으로 비교하지 않는다.

3구간 쉼터에 도달한 기본 모드 15런 중 11런은 기절자가 있어 1마리 50% 부활을 선택했다. 이 선택에서는 다른 생존 동료 HP를 회복하지 못했고, 기절자가 2마리였던 3런은 정예전에 1마리가 기절한 채로 입장했다. 부활 선택 후 평균 HP는 58.45%였다. 기본 4구간 입장 평균 HP는 66.9%, PP는 95.9%였다. 따라서 첫 후속 후보는 초반 부활 선택의 HP 회복 공백으로 좁히고, PP·가격·적 능력치·AI를 한꺼번에 바꾸지 않는다. 자동 전투 판단의 한계도 함께 있으므로 자원 하나만으로 모든 패배를 설명하지 않는다.
