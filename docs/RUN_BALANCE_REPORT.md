| 모드 | 실행/정상 결과 | 완주 | 패배 구간별 건수 | 평균 완료 구간 |

HP/PP는 해당 구간에 도달한 런의 파티 합계 비율 평균이다. 전투 중 누적 소모와 다르며 도달 표본 수가 다른 구간을 동등한 집단으로 비교하지 않는다.

3구간 쉼터에 도달한 기본 모드 15런 중 11런은 기절자가 있어 1마리 50% 부활을 선택했다. 이 선택에서는 다른 생존 동료 HP를 회복하지 못했고, 기절자가 2마리였던 3런은 정예전에 1마리가 기절한 채로 입장했다. 부활 선택 후 평균 HP는 58.45%였다. 기본 4구간 입장 평균 HP는 66.9%, PP는 95.9%였다. 따라서 첫 후속 후보는 초반 부활 선택의 HP 회복 공백으로 좁히고, PP·가격·적 능력치·AI를 한꺼번에 바꾸지 않는다. 자동 전투 판단의 한계도 함께 있으므로 자원 하나만으로 모든 패배를 설명하지 않는다.

10b에서는 기본 모드 첫 쉼터의 구조 선택 한 가지만 후보로 비교한다. 기존 저장은 과거 규칙을 유지하고 전략 모드는 변경하지 않는다. 변경 전후 같은 40조건을 실행한 결과를 아래에 추가하며, 여러 수치를 이 표본에 반복 최적화하지 않는다.

## 10b 비교와 적용

기존 기본값을 유지한 실험 구현 `efe9684c16400703c39de24ddd2dab3895e6c420`을 먼저 커밋·푸시했다. 깨끗한 같은 코드에서 명시적 `normal-rescue-v2`의 [40런](research/run-balance-rescue-20261028.json), 미리 고정한 별도 10시드×두 모드의 [과거 규칙 20런](research/run-balance-holdout-legacy-20261028.json)과 [후보 20런](research/run-balance-holdout-rescue-20261028.json)을 실행했다. 기준선까지 총 120런은 모두 정상 패배이고 오류·제한 초과·미실행은 0이다. [비교 검증 요약](research/run-balance-comparison-20261028.json)에 원시 파일 hash·정확한 대조군 일치·구간별 도달 수를 보관한다.

후보 수치는 한 번 정한 그대로다. 기본 모드 3구간 쉼터에서 부활을 고르면 입장 시 기절한 동료 전원을 HP 50%로 부활시키고 입장 시 살아 있던 동료는 최대 HP의 50%만큼 회복한다. 새로 부활한 동료는 다시 회복하지 않는다. 나머지 선택·구간·전략 모드·PP·상대·가격·AI·기본 콘텐츠는 유지했다.

| 기본 모드 지표 | 본 측정 20시드 과거→후보 | 별도 확인 10시드 과거→후보 |
| --- | --- | --- |
| 평균 완료 구간 | 2.90 → 3.25 | 4.20 → 4.40 |
| 첫 정예 승리 | 8/15 → 12/15 | 7/10 → 9/10 |
| 첫 보스 도달 | 8/20 → 12/20 | 7/10 → 9/10 |
| 첫 상점 도달 | 0/20 → 1/20 | 1/10 → 1/10 |
| 첫 쉼터 출구 평균 HP | 66.88% → 81.40% | 80.48% → 88.32% |
| 부활을 선택한 런의 출구 평균 HP | 58.45% → 78.26% (11쌍) | 64.83% → 80.51% (5쌍) |
| 첫 쉼터 이후 남은 기절자 합계 | 3 → 0 | 0 → 0 |
| 완료 구간 개선/동일/악화 쌍 | 4 / 16 / 0 | 2 / 8 / 0 |

전략 모드 30쌍은 이벤트·집계·노드·입력 수·결과가 정확히 같았다. 기본 모드도 첫 쉼터 이전 30쌍의 기록·입장 자원이 같고, 부활 보완의 영향을 받지 않은 14쌍은 전체 기록과 결과가 같았다. 공개 판단 설정·팀·콘텐츠·엔진·제한 및 전투 정책/관측/엔진 소스 hash가 같다. 보고서의 composite `policy_sha256`에는 서비스·측정기 전체 소스도 들어가므로 프로필 지원 코드를 추가한 전후에는 값이 다르다. 이를 자동 판단 정책 변경으로 해석하지 않는다.

회복 공백 감소가 별도 시드에서도 관찰됐고 진행 악화 없이 초반 도달이 늘어, 새 런 기본값으로 `normal-rescue-v2`를 적용한다. 필드 없는 기존 런은 항상 `balance-v1`이고 이미 저장된 프로필·생성 재시도·전투 checkpoint·미래 조우를 유지한다. 알 수 없는 프로필은 보존하며 진행을 거부한다.

이 결과는 좁은 초반 회복 보완을 지지한다. 모든 런의 완주는 여전히 0이며 첫 보스 이후 표본도 작다. 보스에 새로 도달한 집단의 구성도 달라져 조건부 보스 승률로 효과를 단정하지 않는다. 후반·가격·전체 난이도·실제 사용자 완주율을 해결했다고 주장하지 않으며, 다음 평가는 다른 합법 파티와 공개 판단 정책을 포함해야 한다. 이 자료를 보고 후보 수치나 공개 최종 AI 모델을 다시 튜닝하지 않았다.
