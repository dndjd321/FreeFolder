2026년 10월 27일 통합 검사: Python 94개, Node.js 72개 전부 통과했다. Python 검사는 엔진·HTTP·실제 ASGI WebSocket·방 규칙·저장·학습 계약을 포함한다. 네트워크 응답이 사라져도 이미 적용한 플레이어 입력을 다시 적용하지 않으며, 로그라이크는 worker 장애 후 저장 checkpoint에서 복구한다. 싱글·런·멀티플레이가 애플리케이션 소유의 한 worker를 공유한다.

Ego 브라우저에서 추천 팀으로 싱글 전투, 로그라이크 생성·행동·새로고침 후 복원, 두 탭 방 생성·참가·전투를 확인했다. 멀티플레이는 p1/p2 시점의 비공개 상대 벤치를 숨겼으며, p2가 2턴에 새로고침한 뒤 같은 역할·턴·HP `[82, 183, 202]`로 복원되었다. 로그라이크도 2턴의 HP `[84, 184, 202]`를 그대로 복원했다. 재접속 자동화 검사는 60초 유예, 중복 연결 거부, 대기 중 입력 유지와 제한시간 재개를 포함한다.

현재 신경망은 아래 후속 4에서 검증한 실험 모델이며 기본 컨테이너는 규칙 AI를 제공한다. 브라우저 기록·도감은 해당 브라우저에 저장되며 런 SQLite와 분리되어 있다. 영구 능력치 상승이나 계정 동기화는 구현 범위에 포함하지 않았다. ## 후속 4: AI 개선·분리 평가·재학습

공개 정보 휴리스틱의 무효 공격 반복, 강제 교체 슬롯·상성 판단, HP를 고려한 회복·상태 판단을 수정하고 이전 정책은 비교용으로 남겼다. 정예·보스의 누락된 EV는 기술의 물리·특수·방어 역할에 맞게 채우고 명시한 EV와 저장 checkpoint는 보존한다. 새 탐험에서 기본/전략을 선택할 수 있으며 전략 탐험의 새 정예·보스 전투에 개선한 정책을 적용한다. 과거 저장 전투는 정책 식별자가 없으면 기존 위력 우선으로 이어진다. 알 수 없는 미래 난이도·정책은 백업 보관은 허용하되 현재 버전 복원은 거부한다.

30종의 팀 조합·EV/도구 빌드·seed를 train/validation/test로 분리했다. 조합 수는 2,842/637/581개이고 같은 종과 기술은 공유한다. 모방 학습 8,192표본과 실제 엔진 PPO 65,536단계를 완료했으며 검증으로 선택한 후보는 모방 학습 이후 PPO 16,384단계다. PPO 자기 대전 1,716경기에서 p2 모델 호출 23,816회와 스냅샷 갱신 128회를 기록했다. 최종 test 결과로 가중치·정책·후보를 다시 조정하지 않았다.

고정 평가 4,500경기에 이어 독립 seed에서 팀과 좌석을 교환하는 추가 확인 1,500경기를 실행했다. 실험 후보의 이전 bootstrap 상대 승률은 최초 72.0%, 추가 확인 70.2%(pair-bootstrap 95% 구간 66.6–73.8%)였다. 후보의 규칙 AI 상대 승률은 19.8%라 규칙 AI를 계속 권장한다. 규칙 v2 대 기존 규칙의 추가 확인은 51.4%(48.6–54.2%)여서 일반적 성능 우위를 입증하지 못했다. 6,000경기 전체 불법 행동·제한 초과는 0이고 최초 후보 평가의 상대별 추론 p95 최댓값은 1.80ms였다. 이 평가는 새 체력의 3대3이며 로그라이크 완주율이나 미학습 종 일반화를 의미하지 않는다.

검증 조건을 통과한 `training/models/expedition-v2.pt`를 PyTorch 환경의 실험 신경망 기본 파일로 적용했다. SHA-256은 `20c634f38af9483217c005961b3d00ce53b9af780c825edb5600a5679f6e5610`이며 이전 bootstrap을 보존했다. 기본 Docker에는 PyTorch·신경망 모델을 포함하지 않으며 규칙 AI로 동작한다. [학습 안내](../pokemon_rl/training/README.md)와 [평가 규약](AI_EVALUATION_PROTOCOL.md)에 예산·선택 과정·모델 hash·원시 결과·재현 명령·한계를 기록했다.

브라우저에서 전략 탐험 생성과 실험 신경망의 실제 전투 2턴·HP `[138, 183, 202]`를 확인했다. 기존 합법 파티·행동 정책을 바꾸지 않은 기본 탐험 20구간 완주 검사도 통과했다. 로컬 전체 Python 157개 중 156개 통과·Windows 심볼릭 링크 권한 검사 1개 건너뜀, Node.js 92개 전부 통과했다.
