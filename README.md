## 📂 Projects

### ⚡ Pokemon Battle AI
**PPO 강화학습 AI와 대전하는 포켓몬 배틀 게임**

- **언어**: Python, JavaScript, HTML/CSS
- **프레임워크**: PyQt6, FastAPI, PyTorch
- **AI**: PPO (Proximal Policy Optimization) 강화학습
- **특징**: 
  - 싱글플레이 (AI 대전)
  - 멀티플레이 (WebSocket 실시간 대전)
  - 1000+ 포켓몬, 완전한 배틀 시스템
  - 데스크톱 앱 + 클라우드 배포

📁 **위치**: [`pokemon_rl/`](./pokemon_rl)
